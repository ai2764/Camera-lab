测试阶段

这是用于视频叙事的过程线：先失败，再定位变量，最后把控制权从提示词转移到首尾帧。

1. 纯 I2V 官方基线

用官方 I2V 工作流跑常用运镜。结论是只有 dolly push in 强验证，roll clockwise 弱验证；truck 有横向视差但左右方向不可靠；pull back、pan、tilt、orbit、foreground pass 都不能直接当成功案例。

baseline主要价值：确定失败边界

2. Prompt 敏感度

对 dolly、truck、roll 等尝试短 prompt、物理运动描述、parallax 约束、no zoom/no cut 等写法。结果说明：对已经有深度/前景的图，短 prompt 往往够用；对缺少结构的图，长 prompt 也救不回来。

prompt helps only sometimes不要迷信长提示词

3. Seed hunt

seed 主要影响脸是否被遮挡、身份是否稳定、局部漂移是否严重；它不是“把失败运镜变成功”的主因。`1626970716` 是当前最常用基准 seed，但仍需要按素材验证。

seed 1626970716稳定性基准，不是万能答案

4. 素材结构修正

给不同镜头生成专用源图：宽房间、垂直大厅、非对称 truck 标记、近景遮挡物、3/4 orbit 构图。第一轮太像教学图，箭头和引导线会变成画面伪影；第二轮换成真实场景后更好，但仍有身份漂移。

source matters真实场景优于说明图

5. FLF + image2 尾帧

最新策略：不用 motion control，不靠 NAG/crop 讨论字幕问题，而是给 FLF 一个明确尾帧。结果证明，很多在 I2V 中不稳定的运镜，换成首尾帧约束后可读性大幅提高。

best current route可作为视频主结论

6. 中文 I2V prompt

把 10 个常用镜头全部换成中文短提示词，保持同一张源图、同一个 seed 和 I2V 官方工作流。结果是模型能正常接收中文并输出 video+audio，但运镜可控性没有增强，多数只表现为轻微漂移或主体构图变化。

not better中文适合讲解，不适合作为控制解法

7. 两段式 FLF 多关键帧

用 image2 生成中间关键帧，再把 FLF 拆成 start→middle、middle→end 两段拼接。orbit 和 truck 的方向感增强，但接缝处会有身份、姿态、构图跳变；foreground pass 没有明显优于单段 FLF。

promising but discontinuous证明中间帧有价值，但需要真 FML workflow

素材影响

同一个 prompt 在不同图上差异很大。真正有用的是“画面里本来就有运动线索”：深度、前景、非对称参照、垂直结构、主体侧面信息。

深度和前景比长 prompt 更重要

Dolly、truck、foreground pass 都需要画面里有可被追踪的前后层次。平面头像图容易变成缩放或漂移。

教学图会污染生成

箭头、轨迹线、orbit 标记会被模型当成真实物体，甚至诱发新对象。测试图必须像真实场景。

FLF 的关键是尾帧质量

短 prompt 可用的前提是尾帧已经把目标构图说清楚。尾帧不够物理，视频也会变成构图插值。
